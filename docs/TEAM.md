## Working Agreement

The team will initially develop using a single `main` branch.

No feature branches will be used during the initial development phase.

Major milestones will be committed and pushed to GitHub so that the project history clearly demonstrates progress and team ownership.

## Development Principles

* Communicate before making major architectural changes.
* Test changes against the supplied development dataset.
* Do not access or use hidden evaluation data.
* Keep secrets and API keys out of the repository.
* Document external libraries, models and borrowed code.
* Ensure each team member understands the part of the system they contribute to.
